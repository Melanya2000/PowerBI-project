# ՀՀ բանկային համակարգ 2021–2025 · Power BI

Power BI դաշբորդ Հայաստանի 17 առևտրային բանկերի ակտիվների, վարկերի, ավանդների և շահութաբերության վերլուծությամբ՝ 2021–2025 թվականների համար։

**Հեղինակ՝** Մելանյա Ավետիսյան · Power BI ավարտական նախագիծ, 2026

## Հետազոտական հարցեր
1. Ինչպե՞ս է աճել բանկային համակարգը, և արդյո՞ք մեծանում է կենտրոնացումը։
2. Արդյո՞ք վարկերը ֆինանսավորվում են ավանդներով։
3. Ո՞ր բանկերն են ամենաշահութաբերը, և ինչպե՞ս է դա կապված կապիտալի հետ։

## Եզրակացություններ
- Համակարգի ակտիվները 5 տարում աճել են 1.9 անգամ՝ 6 745-ից 12 796 մլրդ դրամ։ Թոփ 5 բանկերի մասնաբաժինը 57.9%-ից հասել է 61.9%-ի։
- Վարկեր/ավանդներ հարաբերակցությունը 2022-ին իջել է 0.81-ի, քանի որ ավանդներն աճել են 31%-ով։ 2025-ին այն նորից 1.03 է։
- Զուտ շահույթն աճել է 7.5 անգամ, իսկ համակարգի ROE-ն 2025-ին 21.3% է։ Առաջատարներն են Արդշինբանկը (36.6%), Ինեկոբանկը (26.1%) և Ամերիաբանկը (24.5%)։ Շատ կապիտալ ունեցող բանկերն ունեն ավելի ցածր ROE։

## Դաշբորդի էջեր
1. **Գլխավոր** — հիմնական ցուցանիշներ, աճ և թոփ 5 բանկեր
2. **Ակտիվներ** — շուկայի կենտրոնացում, կապիտալ և ROE
3. **Վարկեր և ավանդներ** — վարկեր/ավանդներ հարաբերակցություն
4. **Շահութաբերություն** — ROE, ROA, ակտիվների և պարտավորությունների կառուցվածք
5. **Բանկի պրոֆիլ** — ընտրված բանկի մանրամասները (drillthrough)
